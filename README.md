# Highr

Static real-estate / architecture landing page. Plain HTML, CSS and JS with the Tailwind Play CDN.
No build step: open `index.html` or serve the folder with any static server.

## Structure

```
index.html          page markup (semantic HTML)
css/styles.css      design tokens + custom styles on top of Tailwind
js/                 behaviour, one module per concern
assets/
  images/           photos (projects, team, social, hero, about)
  logos/            brand and client logos (SVG)
  icons/            favicon, UI icons
  fonts/            self-hosted fonts
  data/             json data (e.g. lottie)
```
